About me

A developer who cares about the details clients never see.

I'm Atta e rabi Malik. I build websites and web tools from Lahore, Pakistan, and I've been doing it since 2016, when I started with freelance work.

Story

How I got here.

I started with small freelance jobs and kept going because clients kept coming back. Six of them have returned for more work, which is the best measure I know of whether a project went well.

Most of my day-to-day work is WordPress: custom themes, block-based layouts, Elementor templates and migrations that help sites load faster. When a project needs more than WordPress, I build the front end in plain HTML, CSS and JavaScript, or in React when an interface behaves more like an app.

Alongside client work, I run a small consultancy, Syntrix, and I build my own products, from a streaming platform to a content management system.

How I work

AI-assisted, human-reviewed.

I'm an AI-assisted developer. I use tools like Claude Code to move faster on front-end work, but every line that ships is reviewed, tested and owned by me.

Backend logic, data models and architecture are written by hand. Speed from AI tools is only useful when someone checks the result, and that's my job.

  • Clear communication

    Plain updates, written scopes and no jargon you didn't ask for.

  • Honest scope

    I'll tell you what's realistic for your budget and timeline, even when it's not what you hoped to hear.

  • Fast and accessible

    Sites should load quickly and work for everyone, on any device, with a keyboard or a screen reader.

  • Ownership

    You get clean, documented code and a handover your team can actually use after launch.
