E-Vaccination Management System: one record for every child

A centralised platform for tracking children's immunisations. Parents, hospitals and administrators each get a dashboard suited to their role, with maps, charts and searchable tables.

Project

E-Vaccination Management System

My role

Full-stack development

Stack

Node.js, Supabase, HTML5, Chart.js, Leaflet, Grid.js, Choices.js

Node.jsSupabaseHTML5Chart.jsLeafletGrid.jsChoices.jsAxios

Overview

The E-Vaccination Management System gives one place to track a child's vaccinations. It is built around three roles: Admin, Parent and Hospital.

Screenshots

The challenge

Parents, hospitals and administrators each need a different view of the same immunisation records. The platform had to keep those views separate, and each one had to be easy to use.

Approach

Three role-based dashboards sit on a shared Node.js backend and a Supabase database. I chose Axios for requests and dropped jQuery to keep the front end lean.

Solution

  • Reporting charts with Chart.js.
  • Hospital locations set by clicking a pin on a Leaflet map, rather than typing an address.
  • Data tables with Grid.js, and searchable dropdowns with Choices.js.
